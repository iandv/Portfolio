# Beyond Two Rocks
A 2D Asteroid game with a few extra features.

![1_Main Menu](https://github.com/user-attachments/assets/6b0cd257-e7d2-4025-8267-3f4cf21a5709)

## 🚀 Features
- 3 weapons with different behaviors.
- Rewind powerup that move asteroids back in time for a few seconds.
- Localization option for English and Spanish.
- Option to save game.
